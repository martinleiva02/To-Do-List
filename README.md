# 📝 To-Do List

Aplicación web para crear y administrar una lista de tareas.

El proyecto fue desarrollado con JavaScript vanilla y utiliza LocalStorage para mantener las tareas guardadas incluso después de cerrar o recargar la página.

## 🚀 Funcionalidades

- Agregar nuevas tareas.
- Agregar tareas presionando Enter.
- Marcar tareas como completadas.
- Eliminar tareas.
- Guardar las tareas en LocalStorage.
- Mantener el estado de las tareas después de recargar la página.
- Diseño responsive.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git y GitHub
